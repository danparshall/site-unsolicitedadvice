# CLAUDE.md — Agent instructions for 'site-unsolicitedadvice' website

This repo is a static website. Simple content edits (typo, new link, add a
paragraph) can land directly on main. If you're touching structure or writing
non-trivial CSS/JS, use a branch and write a quick test plan first.

Design language: `fast` — Times New Roman, `#F0F0F0` page + `#444` text,
W3Schools-derived topnav with `#4C8FCD` blue active state. All styling lives in
`fast.css`. Multi-page ready (index.html + about.html + research.html pattern).
